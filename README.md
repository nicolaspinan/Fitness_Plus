# Fitness Plus

Tienda online de suplementos deportivos premium: creatina, pre-entrenos y más. Envío a todo el país.

## Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla)

## Páginas

- **Inicio** — Hero, productos destacados, beneficios
- **Creatinas** — Catálogo de creatinas (BSN, ENA, MyProtein, Star Nutrition)
- **Pre-Entrenos** — Catálogo de pre-entrenos (Pump V8, PreWar)
- **Producto** — Vista detalle con selector de peso y carrito
- **404** — Página personalizada de error

## Cómo verlo

Abrí `index.html` en tu navegador o hostealo con [GitHub Pages](https://pages.github.com/).
